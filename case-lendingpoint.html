Distributed Microservices and a FinTech Platform

Client
LendingPoint
Region
USA
Domain
Salesforce / FinTech platform

The problem

The client operated a high-velocity transactional model split across an on-premise Java Spring Boot backend and external payment networks, including Stripe and ACH. Nightly batch jobs caused data synchronization race conditions when users modified active loans. During peak volume, simultaneous database writes frequently breached Apex CPU time-out limits, which dropped transactions and locked the interface.

The work

  • Replaced batch processing with an event-driven framework using Salesforce Change Data Capture to stream live financial events through an enterprise service bus.
  • Engineered bi-directional WS-Security SOAP services for legacy calls and low-payload REST endpoints to reduce serialization overhead.
  • Offloaded amortization calculations and payment validations into asynchronous queues with Queueable and Batch Apex chaining.
  • Migrated legacy interface systems into Lightning Web Components with client-side caching to cut server round-trips.

The outcome

Reduced data synchronization latency between the Java backend and Salesforce to under one second. Concurrency limits were resolved, Apex transaction timeouts dropped by 84%, and the core checkout pipeline stabilized.
